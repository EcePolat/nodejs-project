🚀 Node.js Role-Based Admin API

A modular and secure backend system built with Node.js, Express, and MongoDB — designed with production-grade architecture patterns.

📌 Project Overview

This project is a role-based admin backend system that simulates real-world enterprise backend architecture.

It focuses on security, scalability, clean code principles, and modular design.

✨ Key Features

🔐 JWT Authentication (Passport)

🛡 Role-Based Access Control (RBAC)

📜 Audit Logging (Database level tracking)

📊 Winston Logger (structured logging)

📦 Excel Import & Export

🔔 Event-Driven Architecture (EventEmitter)

⚙️ Modular Middleware Structure

🧱 Singleton Pattern implementation

🌍 Multi-language Support (i18n)

🧠 Clean Separation of Concerns

🛠 Tech Stack

Node.js

Express.js

MongoDB + Mongoose

JWT + Passport

Winston Logger

Docker (optional deployment)
