🚀 Node.js Role-Based Admin API

A modular and secure Node.js backend architecture built with Express and MongoDB.

This project demonstrates a production-style backend system including authentication, authorization, logging, audit tracking, event-driven structure, and file import/export features.

🧩 Project Overview

This project is a role-based admin backend system designed to simulate a real-world enterprise architecture.

It includes:

🔐 JWT Authentication (Passport)

🛡 Role-Based Access Control (RBAC)

📜 Audit Logging (Database)

📊 Winston Logging (Console)

📦 Excel Import / Export

🔔 Event-Driven Architecture (EventEmitter)

⚙️ Modular Middleware Structure

🧱 Singleton Pattern Usage

🌍 Multi-language Support (i18n)

🧠 Clean Separation of Concerns
