# 🚀 Node.js Role-Based Admin API

A modular and secure backend system built with **Node.js**, **Express**, and **MongoDB**.

## ✨ Features

- 🔐 JWT Authentication (Passport)
- 🛡 Role-Based Access Control (RBAC)
- 📜 Audit Logging (Database)
- 📊 Winston Logging
- 📦 Excel Import / Export
- 🔔 Event-Driven Architecture (EventEmitter)
- ⚙️ Modular Middleware Structure
- 🧱 Singleton Pattern Usage
- 🌍 Multi-language Support (i18n)
- 🧠 Clean Separation of Concerns

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- Passport + JWT
- Winston
- i18n
